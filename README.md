# WG Free Mesh

[English](./README_EN.md) | 简体中文

WG Free Mesh 是一个一站式 WireGuard 管理平台，用于集中管理配置、端点、Mesh 连接、客户端下载、快速组网、备份恢复和 AI 接入。

项目目标是让 WireGuard / AmneziaWG 的多节点运维更简单：在控制台统一生成配置，自动分发到客户端并在目标主机应用。

## 文档

完整使用、部署和开发文档请访问：

[https://wfm.xinghenluyus.cn](https://wfm.xinghenluyus.cn)

## 主要能力

- WireGuard / AmneziaWG 配置管理
- 节点、Mesh 对和快速组网
- 命令行客户端绑定与远程控制
- Docker 部署，支持 SQLite / PostgreSQL
- 应用级快照备份与恢复
- MCP / AI 接入能力
