# 目录结构规划

## 根目录

```text
wg-free-mesh/
  src/
  front/
  client/
  docs/
  docker/
  bak/
```

说明：

- `bak/` 只保存旧代码，作为参考，不参与新架构运行。
- 新代码只写入 `src/`、`front/`、`client/`、`docker/`、`docs/`。
- 根目录不直接放业务源码。

## 后端目录

当前结构：

```text
src/
  README.md
  pyproject.toml
  app/
    main.py
    core/
    api/
      v1/
        routers/
    domain/
    repositories/
    schemas/
    services/
  tests/
```

职责：

- `core/`
  - 配置、日志、异常、安全基础设施。
- `api/v1/`
  - HTTP 路由层，只处理请求、响应和依赖注入。
- `domain/`
  - 领域对象、枚举、领域规则。
- `repositories/`
  - 数据访问接口和实现。
- `schemas/`
  - Pydantic 请求响应模型。
- `services/`
  - 应用服务，编排用例。当前为空，后续业务服务在这里落地。
- `tests/`
  - 后端测试。

## 前端目录

当前结构：

```text
front/
  README.md
  package.json
  pnpm-lock.yaml
  vite.config.ts
  src/
    App.vue
    main.ts
    api/
    assets/
    components/
    router/
    stores/
    types/
    views/
```

职责：

- `views/`
  - 页面级组件。
- `components/`
  - 可复用 UI 组件。
- `components/layout/`
  - 后台布局、导航、页面框架。
- `router/`
  - 路由配置。
- `stores/`
  - Pinia 状态。
- `api/`
  - API 客户端封装。
- `assets/`
  - 全局样式、主题变量。
- `types/`
  - 前端类型定义。

## Docker 目录

当前结构：

```text
docker/
  README.md
  docker-compose.yml
  app/
    backend.Dockerfile
    frontend.Dockerfile
    nginx.conf
  mosquitto/
    mosquitto.conf
```

职责：

- `app/`
  - 后端镜像、前端镜像和 nginx 配置。
- `mosquitto/`
  - MQTT Broker 配置。
