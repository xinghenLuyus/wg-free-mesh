# 目录结构规划

## 根目录

```text
wg-free-mesh/
  src/
  front/
  client/
  docs/
  docker/
```

说明：

- 新代码只写入 `src/`、`front/`、`client/`、`docker/`、`docs/`。
- 根目录不直接放业务源码。

## 后端目录

当前结构：

```text
src/
  README.md
  pyproject.toml
  alembic.ini
  migrations/
  app/
    main.py
    core/
    api/
      client/
      internal/
      v1/
        routers/
    domain/
    data/
    events/
    infrastructure/
    projections/
    schemas/
    services/
  tests/
```

职责：

- `core/`
  - 配置、日志、异常、安全基础设施。
- `api/v1/`
  - HTTP 路由层，只处理请求、响应和依赖注入。
- `api/client/`
  - 客户端绑定入口，面向 `wfmctl bind`。
- `api/internal/`
  - 内部基础设施回调接口，例如 EMQX HTTP Authorization。
- `domain/`
  - 领域对象、枚举、领域规则。
- `data/`
  - SQLAlchemy Engine、schema、仓储入口、数据库快照和数据访问实现。
- `events/`
  - 实时事件发布和配置变更事件计划。
- `infrastructure/`
  - 外部基础设施兼容入口，不承载数据库实现。
- `projections/`
  - 配置列表、配置概览和系统状态等读模型聚合。
- `schemas/`
  - Pydantic 请求响应模型。
- `services/`
  - 应用服务，编排认证、配置、节点、Mesh、控制平面、下载工具、MQTT 和实时事件用例。
- `tests/`
  - 后端测试。

## 前端目录

当前结构：

```text
front/
  README.md
  package.json
  pnpm-lock.yaml
  vite.config.ts
  public/
  src/
    App.vue
    main.ts
    api/
    assets/
    components/
    router/
    stores/
    types/
    views/
```

职责：

- `views/`
  - 页面级组件。
- `components/`
  - 可复用 UI 组件。
- `components/layout/`
  - 后台布局、导航、页面框架。
- `router/`
  - 路由配置。
- `stores/`
  - Pinia 状态。
- `api/`
  - API 客户端封装。
- `assets/`
  - 全局样式、主题变量。
- `public/`
  - Vite 静态资源目录，保存 favicon、品牌 logo 等需要按根路径直接访问的公开资源。
- `types/`
  - 前端类型定义。

## Docker 目录

当前结构：

```text
docker/
  README.md
  sqlite/
    docker-compose.yml
    .env.example
  postgres/
    docker-compose.yml
    .env.example
  app/
    backend.Dockerfile
  emqx/
    base.hocon
    base.tls.hocon
    start-emqx.sh
```

职责：

- `app/`
  - 后端镜像构建。
- `sqlite/`
  - SQLite 部署入口。
- `postgres/`
  - PostgreSQL 部署入口。
- `emqx/`
  - EMQX Broker 配置、TLS/plain 启动配置和启动脚本。

## Client 目录

```text
client/
  README.md
  go.mod
  cmd/
    agent/
    ctl/
  internal/
    agent/
    bind/
    mqtt/
    profile/
    service/
```

职责：

- `cmd/agent/`
  - `wfm-agent` 入口，负责客户端常驻进程。
- `cmd/ctl/`
  - `wfmctl` 入口，负责绑定等命令行操作。
- `internal/bind/`
  - 一次性绑定命令调用和 profile 写入。
- `internal/mqtt/`
  - MQTT 会话、心跳、命令订阅、事件上报和 ACK。
- `internal/service/`
  - Windows/Linux/macOS 服务管理骨架。
