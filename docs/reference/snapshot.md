# 快照参考

快照是应用级备份，不是数据库文件备份。它用于跨 SQLite、PostgreSQL 等数据库迁移应用数据。

## 包含内容

除管理员密码外，数据库中的应用数据都应进入快照，包括：

- 配置
- 端点
- Mesh 对
- 同步态
- 运行态记录
- 客户端绑定状态和 MQTT 凭据
- MCP token 和审计数据
- 设置项

## 不包含内容

管理员密码不进入快照。恢复快照不会覆盖当前部署的管理员密码。

## 加密

快照通过管理员密码加密。没有密码时不能读取快照内容。

## 导出

系统页面可以导出快照。MCP 也可以通过 `write_export_snapshot` 生成 5 分钟短期下载 URL。

MCP 不传输快照文件内容。

## 恢复

恢复只能在系统页面执行。MCP 不提供恢复能力，也不接收快照密码。

恢复时会清理旧业务数据并导入快照数据。恢复后后端会重建运行投影，并在 EMQX 在线时同步 MQTT 用户和授权。

## 兼容

快照会记录当前系统版本，便于判断来源。当前逻辑不做跨版本阻断。
