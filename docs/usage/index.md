# 功能概览

WG Free Mesh 把 WireGuard 网络里常见的几件事放到一个控制台里：建配置、加节点、生成互联关系、下载客户端、下发配置、看状态、做备份。

如果只是少量节点，手写配置也能工作。但节点变多以后，地址、端口、PSK、AllowedIPs、客户端状态和配置同步都会变得难维护。WG Free Mesh 解决的是这部分重复工作。

## 从配置开始

一张网络先从配置开始。配置里定义虚拟网段、默认端口、DNS、MTU，以及使用普通 WireGuard 还是 AmneziaWG 2.0。

然后把设备加成端点。端点里保存虚拟 IP、公网地址、标签、客户端绑定状态和一些高级参数。公网节点可以参与更多自动组网逻辑，普通内网节点也可以作为叶子节点接入。

继续阅读：[配置与端点](/usage/configs)

## 让客户端接入

客户端下载页负责生成对应系统和架构的客户端包。端点控制页会给出绑定命令，客户端绑定后就能接收配置和控制命令。

客户端在线后，可以在控制台里下发配置、启动或停止隧道、查看 WireGuard / AmneziaWG 状态，也可以通过日志排查连接问题。

继续阅读：[客户端与控制](/usage/client)

## 自动生成组网关系

快速组网用来批量重建 Mesh 对。它适合节点发生变化后重新整理拓扑。

目前支持 Gateway、Full Mesh 和 Free Mesh 三种模式。系统会先检查节点是否具备公网地址，再生成对应的 AllowedIPs 和 Mesh 对。

继续阅读：[快速组网](/usage/quick-mesh)

## 暴露内部服务

端口转发用于把 From 端点上的服务端口暴露到 To 端点的指定端口。它适合把 Mesh 内部服务临时挂到另一台节点上访问。

这项能力依赖 To 端点的生命周期命令，所以 To 端点目前应选择 Linux 或 macOS。

继续阅读：[端口转发](/usage/port-forward)

## 备份和迁移

快照是应用级备份。它不依赖具体数据库文件，因此可以从 SQLite 迁移到 PostgreSQL，也可以反向迁移。

快照会包含业务数据，但不包含管理员密码。恢复前建议先导出现有快照，保留回退路径。

继续阅读：[备份与恢复](/usage/backups)

## 接入 AI 工具

AI 接入通过 MCP 提供受控能力。它更适合做查询、辅助排查、生成下载链接，或者在确认后执行有限写操作。

高风险动作，例如快照导入和恢复，仍然需要回到控制台手动完成。

继续阅读：[AI 接入](/ai/)
