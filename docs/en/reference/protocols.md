# Protocols

WG Free Mesh supports WireGuard and AmneziaWG 2.0.

## WireGuard

WireGuard uses standard `[Interface]` and `[Peer]` fields.

## AmneziaWG 2.0

AmneziaWG uses the same general toolchain model with `awg` and `awg-quick` instead of `wg` and `wg-quick`.

Config-level AWG parameters:

- `awg_s1..awg_s4`
- `awg_h1..awg_h4`

Node-level AWG parameters:

- `awg_jc`
- `awg_jmin`
- `awg_jmax`
- `awg_i1..awg_i5`

Empty AWG fields are generated by the backend.
