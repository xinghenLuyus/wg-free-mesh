# 重构完成状态

本文记录当前重构已经完成的系统主线和后续维护规则，不再作为待执行迁移清单使用。

## 已完成范围

- 后端 FastAPI 工程、统一响应、错误处理、配置加载和运行数据目录。
- 认证初始化、登录、登出、当前用户、密码修改和 token secret 轮换。
- 配置、节点、标签、Mesh Link、同步态、系统态、配置下载和批量操作。
- 端点控制、控制日志、批量 probe、节点绑定命令和重置客户端。
- MQTT / EMQX 集成，包括客户端专属账号、HTTP Authorization 回查、心跳、事件、命令投递和 ACK。
- SSE 实时事件，包括认证、连接存活、系统状态、配置列表和配置概览事件。
- 设置页、备份恢复、系统状态聚合和国际化。
- 前端 Vue 3 + Vite + TypeScript 控制台，覆盖配置工作台、节点工作台、Mesh、同步、系统、设置和下载工具。
- Go 客户端 `wfmctl + wfm-agent` 骨架，覆盖绑定、profile、MQTT 会话、心跳、命令处理、ACK 和跨平台服务管理接口。
- Docker 一体化部署和开发期 EMQX 支持。

## 当前实现边界

- 客户端不再使用注册文件或节点公私钥身份体系。
- 动态节点使用后端签发的一次性绑定命令完成 `wfmctl bind`。
- 真正 WireGuard 服务启停和系统级配置应用仍由客户端后续实现接入现有服务管理接口。
- GitHub Release 客户端下载源已在接口中预留，当前实际可用源为本地源码构建。

## 后续维护规则

- 修改 API、数据模型、前后端职责、客户端协议、Docker 部署或安全策略时，必须同步更新 `docs/`。
- 前端不得复制后端业务规则；可被外部 API、客户端或 MCP 复用的规则必须在后端用例中实现。
- 运行数据保持在后端运行数据目录，开发期 `uvicorn --reload` 应排除 `data`，避免产物写入触发重载。
