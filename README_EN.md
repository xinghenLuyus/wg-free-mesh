# WG Free Mesh

English | [简体中文](./README.md)

WG Free Mesh is a one-stop WireGuard management platform for configs, nodes, mesh links, client downloads, quick mesh setup, backups, and AI access.

It helps simplify multi-node WireGuard / AmneziaWG operations: generate configs in one console, distribute them to clients automatically, and apply them on target hosts.

## Documentation

Read the full documentation:

[https://wfm.xinghenluyus.cn/en/](https://wfm.xinghenluyus.cn/en/)

## Features

- WireGuard / AmneziaWG config management
- Nodes, mesh links, and quick mesh generation
- CLI client binding and remote control
- Docker deployment with SQLite / PostgreSQL
- Application-level snapshots
- MCP / AI access
